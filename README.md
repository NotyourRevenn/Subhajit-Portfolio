# Subhajit Mondal — Business & Data Analyst

A high-precision, institutional portfolio website engineered for **Subhajit Mondal** (Business & Data Analyst).

Combines an institutional data terminal aesthetic (Ink neutral ramp, quiet chrome, subtle hairline borders, and emerald telemetry accents) with quantitative case studies and interactive operations models.

---

## Technical Highlights

- **Institutional Design System**:
  - Ink neutral ramp (`#0B0D14` background, `#11141C` raised surfaces, `#181C26` active states).
  - Subtle hairline borders (`rgba(238, 240, 245, 0.08)`) with soft, neutral depth.
  - Quiet chrome navigation and single-line layout without visual clutter or emojis.
  - Precise typography using Plus Jakarta Sans and JetBrains Mono with tabular figures.
- **Quantitative Business Impact**:
  - **₹94.5 Lakhs**: Modeled annual logistics savings from warehouse velocity reallocation.
  - **-18.2% CPU**: Reduced warehouse cost-per-unit from ₹45.5 to ₹37.2.
  - **200,000+ Records**: Modeled into a relational 1 Fact : 4 Dimensions Star Schema.
  - **40% Cycle Time Saved**: Automated Power Query ETL and custom DAX measures.
- **3 Interactive Operations Labs**:
  1. **Warehouse Productivity & Cost-per-Unit (CPU) Model**:
     - Interactive Zone A, B, C, D selector with instant throughput and CPU readouts.
  2. **Dark Store Inventory Turnover & Safety Stock Simulator**:
     - Interactive Days of Inventory Outstanding (DIO) threshold slider with real-time risk alerts.
  3. **Enterprise Sales Margin Intelligence System**:
     - Star Schema table explorer and executable SQL CTE window function runner.
- **Recruiter Fast-Track & Resume Dossier**:
  - 1-click clipboard copy for email (`mondalsubhajit556@gmail.com`) and phone (`+91 6295716179`).
  - Clean printable resume dossier.
  - Fully responsive across desktop, tablet, and mobile viewports.
