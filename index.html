Enterprise Sales Margin Intelligence and Star Schema Architecture

MySQL Window Functions Star Schema CTE Analysis
Problem

200,000+ scattered transactional records masked unmonitored regional discounting and margin erosion in enterprise accounts.

Analysis

Designed a clean 1 Fact to 4 Dimensions Star Schema; authored SQL Common Table Expressions and Window Functions (DENSE_RANK, LAG).

Outcome

Uncovered ₹18.5 Lakhs in margin leakage caused by unapproved discretionary discounts in the East territory.

Relational Schema and SQL Workbench
Fact_Sales_Returns: Central transactional fact table with 200,000+ rows. Measures: Revenue, Discount_Amt, Quantity, Profit.
WITH regional_margin_cte AS ( SELECT Territory, SUM(Revenue) AS Rev, DENSE_RANK() OVER (ORDER BY SUM(Discount) DESC) AS Leak_Rank FROM fact_sales f JOIN dim_region r ON f.Region_ID = r.Region_ID GROUP BY Territory ) SELECT * FROM regional_margin_cte;
