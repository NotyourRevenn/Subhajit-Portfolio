Enterprise Sales Margin Intelligence & Star Schema System

MySQL Window Functions Star Schema Pareto 80/20

SOLUTION Structured into 1 Fact : 4 Dims Star Schema; authored SQL Window Functions (DENSE_RANK, LAG).
RESULT Identified ₹18.5 Lakhs in margin leakage caused by discretionary East Enterprise discounting.
● STAR SCHEMA EXPLORER
FACT_SALES_RETURNS: Central fact table with 200,000+ transactional rows. Measures: Revenue, Discount_Amt, Quantity, Profit.
WITH regional_margin_cte AS (
  SELECT Territory, SUM(Revenue) AS Rev,
  DENSE_RANK() OVER (ORDER BY SUM(Discount) DESC) AS Leak_Rank
  FROM fact_sales JOIN dim_region ON f.Region_ID = r.Region_ID
  GROUP BY Territory
)
